# Fix Workflow

Automate the stories implementation

## Steps
  1. **Check** — Check repo folder for stories                                                          
  2. **Analyze** - Check PRD, Architecture, Plans for any issues or missing details
  3. **Ask** — Ask for any missing details or ambiguous requirement                                          
  4. **Spin Agents** — Spin an agents in parallel waves to work on stories like below:
  5. **TDD** — Create Test cases if missing, create tests for these test cases 
  6. **Run tests** — Run them, they should fail
  7. **Implement** — Impelemnt story Tasks
  6. **Run tests** — Run them again, they should pass, fix until they **pass** (proving the fix works)


  Never skip steps. Never combine steps. Each step must complete before moving to the next.
